# ADR-016：本地文件导入与数据主权入口

## 状态

已采纳（2026-08-13）。

## 背景

Trace 需要让用户把已有的工作痕迹带入工作册，但不能把“选择文件”误解成“自动形成事实”。同时，本地优先意味着用户必须能看见、带走、恢复和清空自己的数据。

## 决策

- 文件导入只接受用户主动选择的 Markdown、JSON 和文本文件；
- 浏览器先解析并展示内存预览，确认前不写入 `SourceRecord`；
- JSON 支持记录数组或 `records`/`items` 数组，每条材料仍是原始记录；缺失日期时明确标记“日期使用导入日”，不把补齐的日期伪装成来源事实；
- 确认导入使用单个 IndexedDB 事务，同时写入 `ImportBatch`、`SourceRecord` 和首个 `RecordRevision`，不自动生成证据；
- 设置与数据页提供 UTF-8、版本化 JSON 备份下载、覆盖式恢复、清空和演示数据重置；恢复与清空均需要二次确认；
- 备份恢复先通过运行时 schema 与敏感字段检查，校验失败时保持原数据库不变。

## 未解决范围

真实在线飞书授权仍由最小本地伴侣的后续阶段承载；当前本地 Codex 会话和飞书导出目录读取器遵循范围选择、预览、确认导入和删除副本边界。本 ADR 不引入 OAuth 后端，也不允许扫描整个 Codex 历史目录。
