# ADR-002：证据类型与认识论身份分离

- 状态：已接受
- 日期：2026-08-03

## 背景

“结果”描述内容在工作中的作用，却不能说明它是否已经确认；“用户确认”描述工作流动作，也不能证明内容客观为真。把这些含义压在一个状态字段中，会让 AI 推测在确认后被误呈现为事实。

## 决策

使用三条独立语义轴：

- `EvidenceType`：行动、问题、决策、结果、反馈、学习、假设；
- `EpistemicKind`：已观察事实、用户判断、AI 推测、假设；
- `ReviewState`：草稿、候选、已确认、已拒绝。

结果另用 `resultStage` 表示阶段性或最终。

## 放弃的选项

- 单一 `status` 枚举：状态组合会快速膨胀且含义模糊；
- 用户一确认就改为事实：把接受表达误当作事实验证；
- 仅靠界面颜色区分：数据导出和未来迁移会丢失语义。

## 后果

领域校验与界面需要同时展示多条轴，但产品可以诚实保留“已确认的 AI 推测”这类真实状态。
