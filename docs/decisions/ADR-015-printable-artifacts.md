# ADR-015：可携带的周报与项目案例导出

状态：已采用

日期：2026-08-13

## 背景

Trace 的价值不只发生在浏览器内。用户需要把经过确认的周报和项目案例带到述职、复盘、作品集或纸面阅读中。直接把页面 DOM 下载下来，会把编辑控件、待处理状态和导航一起带出去，也无法保证来源索引仍然和内容对应。

## 决策

- Markdown 导出从明确的领域修订和证据对象生成，不读取页面 DOM。
- 周报和项目案例的正文保留认识论标签：已确认事实、我的判断、AI 推测、待验证假设；待确认块不会伪装成定稿。
- 导出文末保留证据索引，并带出原始引用摘录；拒绝块不进入正文。
- 项目案例提供独立的打印页路由。打印页隐藏应用导航和操作按钮，保留标题、时间范围、七段内容和证据索引，用户可在 Chromium 的打印对话框中保存 PDF。
- 第一版不承诺复杂排版模板、在线分享链接或服务器端 PDF 生成；这些会把本地优先产品带向文档 SaaS。

## 结果

导出是证据链的另一种表达方式，而不是把当前编辑器截屏或拼接成下载文件。用户可以看到一份适合阅读和打印的案例，同时仍知道每个重要表达来自哪些原始记录。
