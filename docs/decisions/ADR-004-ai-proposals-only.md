# ADR-004：AI 适配器只返回结构化候选

- 状态：已接受
- 日期：2026-08-03

## 背景

AI 可以帮助拆分记录和起草周报，但模型响应不可被视为可信数据库写入。供应商调用散落在界面中也会造成密钥、Prompt、错误处理和测试边界失控。

## 决策

所有模型能力通过 `AiAdapter` 接口接入。适配器只返回带来源 ID 的结构化候选，不直接写数据库。应用用例负责运行时 schema 校验、引用检查、候选状态和事务写入。

公开演示默认使用固定响应；真实调用只允许用户控制的安全端点或本地代理。无 AI 时核心流程仍可用。

## 放弃的选项

- 组件直接调用供应商 SDK：边界分散且难以测试；
- 模型返回后自动确认：违背证据优先；
- 在公开前端保存真实密钥：不可接受的泄露风险。

## 后果

新增适配和应用编排层，但 AI 可替换、可模拟、可失败，并且不能绕开领域规则。
