# ADR-019：用证据包支持求职梳理，不自动替用户决定方向

日期：2026-09-04  
状态：已被 ADR-020 调整

## 背景

产品作者当前需要尽快总结既有工作成果并判断跳槽方向。现有 Trace 已能保存记录、确认结果、整理项目案例和能力主张，但缺少一个把这些材料集中带出、并补充个人偏好与现实约束的入口。

直接增加“自动推荐岗位”会超出证据能够支持的范围。岗位选择还依赖兴趣、城市、薪资、风险承受能力和市场信息；这些不能从工作记录中自动推断。

## 决策

增加“求职”一级入口，提供一个最小纵向切片：

1. 只汇总已确认的结果、反馈、判断、行动、已定稿案例和已确认能力主张；
2. 用户主动填写当前岗位、候选方向、希望增加的工作内容、现实约束和排除项；
3. 导出包含原始依据摘录的 UTF-8 Markdown 求职梳理包；
4. 提供一段后续分析提示词，要求分析者先追问、区分事实与推测，再比较候选方向；
5. 不生成就业竞争力分数，不自动把单项目主张升级为跨项目长期能力，不自动生成成品简历。

## 数据与隐私

求职背景作为 `WorkspaceSettings.careerProfile` 保存在当前浏览器，并进入用户主动下载的 JSON 备份。导出包可能包含公司、客户或未公开工作信息，页面必须提醒用户在分享前检查和脱敏。

## 后果

- 用户今天即可把 Trace 资料整理成可供深入分析的输入，不依赖真实 AI 端点或在线飞书授权；
- Trace 保持“证据先于结论”的边界；
- 后续若要自动生成简历、读取职位市场信息或做岗位匹配，需要新增独立验收标准和数据来源说明。
