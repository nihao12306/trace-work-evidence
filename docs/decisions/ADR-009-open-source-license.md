# ADR-009：公开许可证选择

## 状态

已决定：先采用 MIT 作为公开发布默认许可证。版权主体使用 `Trace / 迹 contributors` 占位，正式发布前可替换为作者希望展示的姓名或组织名。

## 背景

Trace 计划公开放到 GitHub，但工作证据产品同时包含代码、演示数据、截图和文档。许可证必须在公开发布前由项目作者明确选择，不能由实现者默默替代。

## 候选

- **MIT**：文本短、使用和再发布限制少，适合希望降低采用门槛的个人作品；不提供专利授权条款。
- **Apache-2.0**：包含明确的专利授权和相关保护，文本更长，使用者需要遵守更多通知要求。

## 决策

Trace 采用 MIT。仓库根目录 `LICENSE` 已包含完整文本，README 已说明许可证和版权主体。若作者之后选择 Apache-2.0，只需替换许可证文本、README 说明和本 ADR，不影响产品数据模型或运行方式。
