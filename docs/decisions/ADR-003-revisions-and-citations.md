# ADR-003：保留原始修订与引用摘录

- 状态：已接受
- 日期：2026-08-03

## 背景

用户会补充或修改记录。如果直接覆盖原文，已经形成的证据和结论会悄然改变来路；只保存字符位置也会在中文文本改动后失效。

## 决策

首次保存的原文永久保留，后续编辑创建 `RecordRevision`。引用保存目标 ID、记录 ID、引用摘录快照和可选字符范围。修订后引用可以变为过期，但摘录不能被替换。

周报和项目案例定稿后同样创建新修订，不覆盖旧定稿。

## 放弃的选项

- 直接覆盖原记录：破坏历史证据链；
- 只复制摘录、不保留目标：无法回到完整上下文；
- 只保存字符范围：对修订和 Unicode 文本过于脆弱。

## 后果

数据量会略有增加，删除策略更谨慎，但用户可以准确回答“这条结论当时依据了什么”。
