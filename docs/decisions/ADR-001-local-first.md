# ADR-001：第一版本地优先且无账号

- 状态：已接受
- 日期：2026-08-03

## 背景

工作证据常包含尚未公开的公司信息、个人判断和不完整结果。第一位真实用户需要低成本、无需部署后端即可连续使用，并能把项目公开到 GitHub。

## 决策

第一版不提供账号和服务器，业务数据默认保存在浏览器 IndexedDB。产品明确说明浏览器数据可能被清理，并提供带格式版本的 JSON 全量备份、恢复和清空能力。

## 放弃的选项

- 云数据库与登录：增加隐私、部署和账户维护成本；
- 仅使用 `localStorage`：不适合结构化对象、索引、迁移与事务；
- 把本地保存描述为永久可靠：不诚实。

## 后果

用户可以不配置服务直接使用，但跨设备同步不在第一版范围。数据可靠性依赖清楚的风险说明和经过测试的备份恢复。
