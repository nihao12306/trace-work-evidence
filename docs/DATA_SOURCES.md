# Trace 数据来源边界

Trace 的默认状态是“不连接任何外部来源”。用户可以只使用手动记录和文件导入，核心证据闭环不依赖飞书、Codex 或 AI。

## 来源状态

| 来源       | 默认状态                 | 第一版边界                                                                                         | 存储位置                         |
| ---------- | ------------------------ | -------------------------------------------------------------------------------------------------- | -------------------------------- |
| 手动记录   | 开启                     | 用户主动输入                                                                                       | 当前浏览器 IndexedDB             |
| 文件导入   | 按次选择                 | 支持 Markdown/JSON/文本；用户选择后先预览，再确认导入                                              | 当前浏览器 IndexedDB             |
| 飞书       | 未配置                   | 只读用户明确配置的本地导出/同步目录；不登录飞书账号、不做后台同步                                  | 导入后的材料在本地               |
| Codex 历史 | 可检测但不自动读取       | 只读配置 Codex 根目录下的 `sessions`/`archived_sessions`；只提取用户消息和 Codex 最终消息          | 导入后的材料在本地               |
| AI 分析    | 关闭 / 演示 / 自定义端点 | 关闭不请求；演示无网络；自定义端点仅在用户主动触发并确认范围后发送当前任务所需输入，输出只能是候选 | 演示在本地；自定义端点由用户负责 |

## 本地伴侣

本地伴侣是运行在用户电脑上的无界面中转进程，不是 Trace 作者的服务器。它现在包含两个只读适配器：

1. Codex：默认读取 `%USERPROFILE%\\.codex\\sessions` 和 `archived_sessions` 下的 JSONL，会话中只提取 `user_message` 与 `agent_message`；不打开 `auth.json`、SQLite、日志、memory 或其他文件。
2. 飞书：读取 `TRACE_FEISHU_EXPORT_DIR` 指向的本地目录中的 JSON、Markdown 和文本文件；目录由用户自行导出或同步，伴侣不会通过浏览器登录飞书。

连接流程固定为：

```text
用户运行本地伴侣
→ Trace 健康检查显示来源状态
→ 用户选择飞书或 Codex，并填写范围
→ 伴侣按范围读取并返回预览
→ 用户勾选材料并确认
→ 写入本地 SourceRecord + ImportBatch
→ 用户可请求生成保守证据草稿
→ 用户逐条确认后，证据才能用于周报/案例/能力主张
```

伴侣未运行或来源未配置时，手动记录、文件导入和核心证据闭环仍可使用。预览失败不会写入半份材料。

## 范围语法

预览请求的 `scope` 支持：

- `全部`：读取来源适配器可见范围内的材料；
- `最近7天` / `last 7 days`：按材料日期过滤；
- `2026-08-01..2026-08-18`：日期范围；
- 普通关键词：匹配标题、正文、日期或外部 ID。

Codex 会话不需要用户转换格式。飞书 Markdown/文本文件按一份文件一条材料读取；JSON 可以是数组，或包含 `items`/`records` 数组。任何材料进入工作册后仍是原始材料，不是已验证事实。

## 删除与撤销

设置页的“移除本地副本”只处理已经写入工作册的某一批记录。删除前会列出证据、周报、案例或能力线索等影响引用；没有有效引用的原始记录可以移除，已经进入证据链的记录会保留，避免结论失去来路。它不代表已经断开在线飞书/Codex 授权：当前版本没有在线授权，因此不存在可撤销的外部令牌。停止伴侣或移除环境变量即可停止本地来源读取。

## 公开仓库注意事项

- 不提交飞书 App Secret、Token、refresh token、Codex 会话凭证或真实导出；
- 不提交真实公司资料、人员姓名、工作链接或带业务数据的截图；
- `.env` 不能因为未提交就视为安全，前端构建变量也不能存放秘密；
- 演示数据必须完全虚构，并能从全新 clone 复现；
- Codex 本地适配器依赖可变化的会话 JSONL 形状；格式变化时应报错或返回空预览，不能猜测并写成事实。
